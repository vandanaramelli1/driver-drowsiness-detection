\# Driver Drowsiness Detection System



Real-time driver monitoring system to detect drowsiness

using facial landmark detection.



\## Features

\- Eye closure detection using MediaPipe

\- Head tilt monitoring

\- Real-time SMS alerts via Twilio when drowsiness detected



\## Tech Stack

\- Python, MediaPipe, Twilio



\## How to run

pip install mediapipe twilio opencv-python

python drowsiness.py
